# LUNEX DIRECTOR AI

Прототип отдельного директора игровой разработки. Русскоязычная веб-панель для Android, очередь задач, копирование промптов, получение отчётов, журнал действий, просмотр GitHub Pull Requests и GitHub Actions в режиме только чтения.

## Запуск

Запускать из папки репозитория под отдельным непривилегированным пользователем. Требуется Python 3.11+, дополнительных Python-пакетов нет.

```bash
export DIRECTOR_ADMIN_PASSWORD='YOUR_STRONG_PASSWORD_16_PLUS'
export DIRECTOR_DB='./var/tasks.sqlite3'
export DIRECTOR_REPOSITORY='maillunex-lang/LunexEconom'
python3 -m director.app
```

При необходимости GitHub-токен с **только read-only permissions** можно указать через `DIRECTOR_GITHUB_TOKEN` в локальном серверном окружении, но никогда не коммитить. Для публичного репозитория возможно чтение без токена, с ограничениями GitHub API.

Программа слушает только `127.0.0.1:18798`. Публиковать через интернет без HTTPS, проверенной аутентификации, ограничений на перебор пароля и дополнительных проверок **нельзя**. На первом этапе использовать только защищённый SSH-туннель.

## Текущий функционал

- Авторизация по паролю, короткоживущая серверная сессия, HttpOnly cookie, CSRF-токен, журнал действий
- Добавление заданий и промптов, ручные статусы, отчёты и ссылки PR
- Получение PR и последних запусков CI из GitHub в режиме чтения
- SQLite отдельно от LunexEconom; нет операций слияния или управления игровым сервером

## Ещё не реализовано

GitHub App и Webhooks, автоматическая сверка данных, AI-проверка кода, автоматическая выдача задач, merge-manager, MFA, устойчивые сессии и безопасный публичный HTTPS-шлюз.

## Политика безопасности

Изменения в `main` игры и производство на VPS не делаются. Автоматические слияния отключены. Для полного решения будут обязательны branch protection, актуальная проверка SHA, required checks, строгие права GitHub App и аудит.
